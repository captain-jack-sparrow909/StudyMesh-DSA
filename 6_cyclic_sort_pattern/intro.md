The Cyclic Sort pattern is an in-place, O(n) time complexity sorting technique used when array elements fall within a known, continuous range (like 1 to n or 0 to n). Instead of comparing items against each other like traditional sorting algorithms, Cyclic Sort maps each value directly to its corresponding array index.💡 Core IntuitionIf you are given an unsorted array of size n containing numbers from 1 to n, you already know exactly where each number belongs:The value 1 belongs at index 0.The value 2 belongs at index 1.Any value x belongs at index x - 1.The algorithm iterates through the array. If the current element is not at its correct index, it swaps places with whatever element is currently occupying its target index. This process repeats until the correct element lands on the current index, after which the loop moves forward.
